# API Structure Overview

## Helpers and Static Folders

### `Helpers`
Contains reusable utility functions shared across the API.

---

### `static`
Houses additional API documentation with an improved layout compared to the default generated documentation.

---

## Files

### `security.py`
Responsible for managing API security.
- API key handling

### `main.py`
Entry point of the API application.

- Application initialization  
- Middleware configuration  
- Global settings  
- Router registration  

### `dfs.py`
Handles the DFS endpoint logic.

- Endpoint definitions  
- Request handling
