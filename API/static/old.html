Different Odds API

A powerful external 3rd party API to interact with various sportsbooks, allowing you to fetch and display data in multiple formats.

⚡

Fast & Reliable

High-performance API with consistent uptime and fast response times.

🔒

Secure Authentication

API key-based authentication to keep your data secure and protected.

📊

Multiple Formats

Flexible data formatting options to match your application needs.

Authentication

This API requires authorization to access endpoints. Ensure you have the necessary credentials to interact with the API. You can authenticate using either query parameters or headers.

Base URL

https://api.differentodds.com

Endpoints

Fetch Data

GET/dfs/{dfs_books}

Fetches DFS data from various sportsbooks.

GET/sportsbook/{sportsbooks}

Fetches sportsbooks data from various sportsbooks.

Parameters

Both → Sportsbook & DFS Require this | Do not pass in both api_key and x-api-key - Pick only 1

DFSdfs_bookspath parameter

Comma-separated DFS books (ex. parlayplay, underdog). You can also just pass in a single DFS book. Keep in mind the more DFS books you pass in, the slower the response time will be, due to the large amount of data being returned.

Sportsbooksportsbookspath parameter

Comma-separated sportsbooks (ex. onyx). You can also just pass in a single sportsbook. Keep in mind the more sportsbooks you pass in, the slower the response time will be, due to the large amount of data being returned.

Bothformatter-optionheader

Available values: league_formatter, event_formatter, base_formatter (default: event_formatter).

Bothapi_keyquery

API key for authentication.

Bothx-api-keyheader

API key for authentication. Example: x-api-key: your_api_key

Get JSON URL

GET/dfs/json/{dfs_books}

Returns the data for the specified DFS book in JSON - Just a quick way to view the data in the browser.

GET/sportsbook/json/{sportsbook}

Returns the data for the specified sportsbook in JSON - Just a quick way to view the data in the browser.

Parameters

DFSdfs_bookspath parameter

The DFS book to retrieve JSON data for (ex. underdog)

Sportsbooksportsbookpath parameter

The sportsbook to retrieve JSON data for (ex. onyx)

Bothapi_keyquery

API key for authentication

List DFS Books

GET/list_dfs_books

Lists all available DFS books in a string

GET/list_sportsbooks

Lists all available sportsbooks in a string

Parameters

None

Responses

200 OK: Successful response with data
json 
{ "betr": "Betr", "boom": "Boom", "dk_picksix": "Dk_Picksix", "dabble": "Dabble", "prizepicks": "Prizepicks", "sleeper": "Sleeper", "underdog": "Underdog" }

Get Prizepick Multi

POST/dfs/prizepick/multi

Returns the multiplier for a given prizepick slip.

Parameters

DFSmulti_datapayload

Pass in a JSON object with a key of "multi_data" and a value of a list of bet_type and projection IDs for each player in the bet slip

Bothapi_keyquery

API key for authentication

Example Request & Response

Request Body
json 
{ "multi_data": [ { "bet_type": "over", "projection_id": "3982967" }, { "bet_type": "over", "projection_id": "3982886" } ] }
Response
json 
{ "power": { "multi": 11.5 }, "flex": { "multi": { "3": 1.5, "4": 6 } } }

Error Handling

The API follows standard HTTP status codes:

200 OK:Request successful
400 Bad Request:Invalid sportsbook(s) or DFS book provided
401 Unauthorized:Authentication required
404 Not Found:Resource not found
500 Data Not Found:No data found for that book
