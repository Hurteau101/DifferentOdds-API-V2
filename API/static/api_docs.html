Different Odds API

A powerful external 3rd party API to interact with various sportsbooks, allowing you to fetch and display data in multiple formats.

⚡

Fast & Reliable

High-performance API with consistent uptime and fast response times.

🔒

Secure Authentication

Access is protected through API key-based authentication.

📊

Multiple Formats

Flexible data formatting options to match your application needs.

Authentication

This API uses an API key for authentication. Majority of requests to the API endpoints must include your API key in the header.

X-API-KEY: YOUR_API_KEY

Requests without a valid X-API-KEY in the header will result in a 401 Invalid/Missing API Key error.

Base URL

https://api.differentodds.com

GET /dfs/odds

Fetches odds for one or more specified DFS Books
If multiple books are requested, the response will be returned as key/value pairs, where each key is the book name and the value contains that book’s data.

Parameters

books query parameter

One or more DFS book identifiers, passed as repeated books query parameters. Example request URL:

/dfs/odds?books=draftkings_6&books=boom

Headers

X-Format header

Returned formatting options, passed in as a header. Allowed values: Base, Game. If omitted, defaults to Game.

Base:
Returns data in a dict with no grouping.

Game:
Returns data in a dict, grouped by games.

Error Handling

The API follows standard HTTP status codes:

200 OK: Request successful
400 Bad Request: Invalid parameters or request body
401 Unauthorized: Authentication required or invalid API key
404 Not Found: Resource not found
500 Server Error: An error occurred on the server
